# Mídias do deck "From Copy to Copied"

Coloque os arquivos **nesta pasta** com exatamente estes nomes. O deck detecta sozinho:
se o arquivo existir, ele vira fundo do slide (vídeo em loop e mudo, ou imagem com efeito
Ken Burns); se não existir, o slide usa o fundo animado (chuva de hanzi ou rede de dados).
Cada slide aceita **vídeo ou imagem**: basta um dos dois nomes listados.

Recomendações:
- Vídeo: MP4 (H.264), 1920×1080, 10–30 s em loop, **sem áudio**, até ~15 MB cada.
- Imagem: JPG, 1920×1080 ou maior, até ~1 MB.
- O lado esquerdo do slide fica escurecido para o texto. Prefira o assunto principal à direita.
- Use material com direito de uso (banco de imagens ou fotos e vídeos próprios da imersão).
